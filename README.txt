PP RENAMER v0.2b
=================

PP Renamer — небольшая программа для автоматического переименования
платежных поручений в формате PDF.

Программа извлекает из платежки номер, получателя, сумму и при необходимости ИНН, после чего
сохраняет файл с понятным именем, например:

    N 007 - ИП Пупкин Василий Васильевич - 10 322-00 руб.pdf


КАК ПОЛЬЗОВАТЬСЯ
----------------

1. Запустите PP Renamer.exe.
2. Перетащите в большую область окна:
   • один PDF;
   • несколько PDF;
   • папку с платежками;
   • архив ZIP, 7Z или RAR.

3. Укажите папку, куда нужно сохранить переименованные файлы.
4. Проверьте или измените паттерн имени.
5. Дождитесь завершения обработки.

ВАЖНО:
Оригинальные файлы не изменяются.
Переименованные копии сохраняются в выбранную папку.


ПАТТЕРН ИМЕНИ
-------------

По умолчанию используется:

    N {number} - {recipient} - {amount} руб.pdf

Доступные переменные:

    {number}        — номер платежного поручения
    {recipient}     — получатель платежа
    {recipient_inn} — ИНН получателя платежа
    {amount}        — сумма платежа
    {date}          — дата платежки
    {payer}         — плательщик
    {payer_inn}     — ИНН плательщика

Подсказку по переменным можно открыть кнопкой "?"
рядом со строкой паттерна.

Если переменная указана в паттерне, но программа не смогла прочитать
соответствующий реквизит, вместо значения будет подставлено [ERROR],
а файл будет скопирован в папку для пропущенных.


ПОДДЕРЖИВАЕМЫЕ ФОРМАТЫ
----------------------

Программа принимает:

    • PDF-файлы;
    • папки с PDF;
    • ZIP-архивы;
    • 7Z-архивы;
    • RAR-архивы.

Для архивов и папок выполняется поиск платежек
во вложенных папках.


ЛОГ РАБОТЫ
----------

В нижней части окна отображается ход обработки:

    • какие файлы обработаны;
    • какие файлы пропущены;
    • ошибки распознавания;
    • итоговый результат.


СВОРАЧИВАНИЕ В ТРЕЙ
-------------------

При сворачивании программа может оставаться в системном трее.
Чтобы вернуть окно, нажмите на значок программы в трее.
