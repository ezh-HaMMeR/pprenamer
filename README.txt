PP RENAMER v2026.09.21
======================

PP Renamer — Windows-приложение для автоматического переименования
платежных поручений в формате PDF.

Программа извлекает номер платежного поручения, дату документа,
получателя, сумму и ИНН, после чего сохраняет файл с понятным именем:

    N 193061 - ООО РУСУ - 106 395-54 руб.pdf


КАК ПОЛЬЗОВАТЬСЯ
----------------

1. Запустите PPRenamer.exe.
2. Перетащите в большую область окна один или несколько PDF,
   папку с платежками либо архив ZIP, 7Z или RAR.
3. Укажите папку, куда нужно сохранить переименованные файлы.
4. Проверьте или измените паттерн имени.
5. Дождитесь завершения обработки.

По умолчанию оригинальные файлы не изменяются: программа создаёт
переименованные копии. Режим перемещения можно включить в настройках.


ИЗВЛЕЧЕНИЕ РЕКВИЗИТОВ
---------------------

Поддерживаются названия получателей, перенесённые на несколько строк.

Полные организационно-правовые формы сокращаются автоматически:

    Общество с ограниченной ответственностью -> ООО
    Индивидуальный предприниматель            -> ИП
    Акционерное общество                       -> АО
    Публичное акционерное общество             -> ПАО

Переменная {date} содержит дату самого платежного поручения, а не дату
формирования или выгрузки PDF из верхнего колонтитула.

В формах, где название организации расположено перед подписью поля
"Получатель", программа извлекает его из блока банка получателя.
Пометка "М.П." (место печати) не используется как имя контрагента.


ПАТТЕРН ИМЕНИ
-------------

По умолчанию используется:

    N {number} - {recipient} - {amount} руб.pdf

Доступные переменные:

    {number}        — номер платежного поручения
    {recipient}     — получатель платежа
    {recipient_inn} — ИНН получателя
    {amount}        — сумма платежа
    {date}          — дата платежного поручения
    {payer}         — плательщик
    {payer_inn}     — ИНН плательщика

Если обязательный реквизит не распознан, вместо значения подставляется
[ERROR], а файл копируется в папку пропущенных.


ПОДДЕРЖИВАЕМЫЕ ИСТОЧНИКИ
------------------------

    • отдельные PDF-файлы;
    • папки с PDF;
    • ZIP-архивы;
    • 7Z-архивы;
    • RAR-архивы;
    • вложенные папки и архивы.

Для RAR может потребоваться установленный 7-Zip, WinRAR или unrar.


ЛОГИ И ПРОПУЩЕННЫЕ ФАЙЛЫ
------------------------

В нижней части окна отображается ход обработки. Проблемные файлы
помещаются в отдельную настраиваемую папку. Если она совпадает с папкой
результата, к имени можно добавить специальный префикс.

Диагностические файлы:

    payment_renamer.log
    payment_renamer_crash.log
    debug_console.log — создаётся при запуске debug_run.bat
