# PP Renamer

Windows-приложение с графическим интерфейсом для автоматического переименования платежных поручений в PDF.

Программа извлекает номер платежного поручения, дату документа, получателя, сумму и ИНН, после чего копирует или перемещает файл под понятным именем.

Формат имени по умолчанию:

```text
N {number} - {recipient} - {amount} руб.pdf
```

Пример:

```text
N 193061 - ООО РУСУ - 106 395-54 руб.pdf
```

Готовую Windows-версию можно скачать на странице [Releases](https://github.com/ezh-HaMMeR/pprenamer/releases/latest).

## Возможности

- Перетаскивание отдельных PDF, нескольких файлов, папок и архивов в окно программы.
- Рекурсивный поиск PDF во вложенных папках и архивах ZIP, 7Z и RAR.
- Поиск PDF во вложенных архивах, например ZIP внутри 7Z.
- Копирование или перемещение переименованных файлов в выбранную папку.
- Настраиваемый паттерн имени файла.
- Отдельная папка для файлов, в которых не удалось извлечь обязательные реквизиты.
- Настраиваемый префикс проблемных файлов, если папка результата и папка пропущенных совпадают.
- Выбор поведения при совпадении имён: создать уникальное имя, перезаписать или пропустить.
- Журнал обработки и диагностический лог аварий.
- Сворачивание приложения в системный трей.

## Извлечение реквизитов

- Поддерживаются названия получателей, перенесённые на несколько строк.
- Полные организационно-правовые формы автоматически сокращаются:
  - `Общество с ограниченной ответственностью` → `ООО`;
  - `Индивидуальный предприниматель` → `ИП`;
  - `Акционерное общество` → `АО`;
  - `Публичное акционерное общество` → `ПАО`.
- Переменная `{date}` использует дату самого платежного поручения, а не дату формирования или выгрузки PDF из верхнего колонтитула.
- Если обязательное поле не распознано, в имя подставляется `[ERROR]`, а файл помещается в папку пропущенных.

## Запуск готовой версии

1. Скачайте архив последнего выпуска со страницы [Releases](https://github.com/ezh-HaMMeR/pprenamer/releases/latest).
2. Распакуйте архив в обычную папку.
3. Запустите `PPRenamer.exe`.

Установка Python для готовой версии не требуется.

## Установка и запуск из исходников

1. Скачайте или клонируйте репозиторий.
2. Запустите `install_requirements.bat`.
3. Запустите `run.bat`.

Для установки зависимостей и запуска одной командой можно использовать `setup_and_run.bat`.

## Сборка EXE

Запустите:

```bat
build_exe_onefile.bat
```

Готовый файл будет создан по адресу:

```text
dist\PPRenamer.exe
```

## Доступные переменные паттерна имени

```text
{number}        — номер платежного поручения
{recipient}     — получатель платежа
{recipient_inn} — ИНН получателя
{amount}        — сумма платежа
{date}          — дата платежного поручения
{payer}         — плательщик
{payer_inn}     — ИНН плательщика
```

Например:

```text
{date} - N {number} - {recipient} - {amount} руб.pdf
```

## Настройки

Настройки сохраняются в `settings.json` рядом с программой. В окне настроек можно выбрать:

- папку результата и папку пропущенных файлов;
- копирование или перемещение исходников;
- обработку вложенных папок и архивов;
- поведение при совпадении имён;
- формат суммы и паттерн имени;
- параметры системного трея и логирования.

## Архивы

ZIP обрабатывается средствами Python. Для 7Z используется `py7zr` или установленный 7-Zip.

Для распаковки RAR обычно требуется 7-Zip, WinRAR или `unrar`. Программа автоматически проверяет стандартные пути установки 7-Zip и системный `PATH`.

## Диагностика

- `payment_renamer.log` — журнал обработки файлов;
- `payment_renamer_crash.log` — сведения об аварийном завершении;
- `debug_run.bat` — запуск с записью консольного вывода в `debug_console.log`.

## Текущий выпуск

Версия `v2026.09.21` дополнительно исправляет распознавание форм Т-Банка, где название организации находится перед меткой «Получатель». Служебная пометка `М.П.` («место печати») больше не может попасть в имя файла вместо контрагента.
