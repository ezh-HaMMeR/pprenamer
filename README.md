# Payment PDF Renamer

Небольшое Windows GUI-приложение для переименования платежных поручений в PDF.

Формат имени по умолчанию:

```text
N {number} - {recipient} - {amount} руб.pdf
```

Пример:

```text
N 007 - ИП Пупкин Василий Васильевич - 10 322-00 руб.pdf
```

## Что умеет

- Перетаскивание PDF-файлов в окно программы.
- Перетаскивание папок.
- Рекурсивный поиск PDF во вложенных папках.
- Перетаскивание архивов ZIP / 7Z / RAR.
- Рекурсивный поиск PDF внутри архивов.
- Поиск PDF во вложенных архивах: например, ZIP внутри 7Z, RAR внутри папки и т.д.
- Копирование переименованных PDF в папку результата.
- Настраиваемый паттерн имени файла.
- Лог ошибок и хода работы.
- Сворачивание в системный трей.

## Установка и запуск из исходников

1. Распакуйте архив проекта в обычную папку.
2. Запустите:

```bat
install_requirements.bat
```

3. Затем запустите:

```bat
run.bat
```

Можно сразу запустить:

```bat
setup_and_run.bat
```

## Сборка EXE

Сборка в один файл:

```bat
build_exe_onefile.bat
```

После сборки EXE будет здесь:

```text
dist\PaymentRenamer\PaymentRenamer.exe
```

## Важное про RAR

ZIP работает через стандартную библиотеку Python.

7Z работает через `py7zr`, который ставится из `requirements.txt`.

RAR обычно требует внешний распаковщик. Самый простой вариант для Windows — установить 7-Zip и убедиться, что есть один из вариантов:

- `C:\Program Files\7-Zip\7z.exe`
- или `7z.exe` доступен через PATH
- или установлен WinRAR / unrar, который может использовать библиотека `rarfile`

Если RAR не распаковывается, программа напишет ошибку в лог.

## Настройки

Настройки сохраняются в `settings.json` рядом с программой.

Основные настройки доступны через кнопку **Настройки**:

- Копировать или перемещать исходники.
- Обрабатывать вложенные папки.
- Рекурсивно искать PDF внутри архивов и вложенных архивов.
- Обрабатывать ZIP / 7Z / RAR.
- Что делать при совпадении имени файла.
- Формат суммы.
- Сворачивание в трей.
- Лог-файл.

## Доступные переменные паттерна имени

```text
    {number}        — номер платежного поручения
    {recipient}     — получатель платежа
    {recipient_inn} — ИНН получателя платежа
    {amount}        — сумма платежа
    {date}          — дата платежки
    {payer}         — плательщик
    {payer_inn}     — ИНН плательщика
```
